# AtlasBridge Icon Assets

Generated from the provided AtlasBridge brand board.

## Recommended usage

### Web UI
- `web/favicon.ico` -> `web/public/favicon.ico`
- `web/favicon-32x32.png` -> `web/public/favicon-32x32.png`
- `web/apple-touch-icon.png` -> `web/public/apple-touch-icon.png`
- `web/icon-192.png` -> `web/public/icon-192.png`
- `web/icon-512.png` -> `web/public/icon-512.png`

### Dashboard
- `logo/atlasbridge-logo-mark-512.png` for header/sidebar logo.
- `logo/atlasbridge-logo-mark-256.png` for compact sidebar logo.

### Tray / Desktop App
- `app/atlasbridge-app-icon-256.png` for tray icon source.
- `app/atlasbridge-app-icon-1024.png` for high-resolution app icon source.
- Convert to `.ico` for Windows executable resources if needed.

## Notes
- Logo mark PNG files have transparent background.
- App icon PNG files include a dark rounded-square background.
- Favicon uses the app icon style for better visibility at small sizes.
