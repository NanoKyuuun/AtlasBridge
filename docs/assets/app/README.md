# AtlasBridge App Assets

This folder contains the prepared AtlasBridge app icon sources.

## Available Sources

- `app/atlasbridge-app-icon-256.png` - tray and Windows app icon source
- `app/atlasbridge-app-icon-1024.png` - high-resolution app icon source
- `logo/atlasbridge-logo-mark-512.png` - dashboard header/sidebar logo
- `logo/atlasbridge-logo-mark-256.png` - compact dashboard logo
- `web/favicon.ico` - browser favicon source
